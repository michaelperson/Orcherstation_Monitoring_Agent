# Wi-Fi des salles de réunion

## Réseau à utiliser
Les salles de réunion utilisent le réseau **NordTech-Meet** (authentification avec le compte NordTech). Le réseau NordTech-Invités est réservé aux visiteurs.

## Coupures répétées
1. Oublier le réseau NordTech-Meet, puis s'y reconnecter.
2. Vérifier que le poste n'est pas en mode économie d'énergie Wi-Fi.
3. Si la coupure touche toute une salle, noter le nom de la salle et l'heure : c'est probablement la borne, ouvrir un ticket réseau pour la file N2-infra.
