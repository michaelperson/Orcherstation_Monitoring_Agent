# Erreur 0x80070005 lors d'une mise à jour Windows

## Cause
Le code 0x80070005 signifie « accès refusé » : la mise à jour n'a pas les droits nécessaires, souvent après une installation interrompue.

## Procédure
1. Redémarrer le poste, puis relancer Windows Update.
2. Si l'erreur persiste, ne pas tenter de modifier les droits système : ouvrir un ticket logiciel en indiquant le code d'erreur exact. Le N2 réinitialisera les composants de mise à jour à distance.
