# Imprimante bloquée ou file d'impression figée

## Procédure
1. Éteindre l'imprimante 30 secondes, puis la rallumer.
2. Vider la file d'impression : Paramètres > Imprimantes > Ouvrir la file d'attente > Annuler tous les documents.
3. Relancer l'impression.

## Bourrage papier
Ouvrir le capot indiqué sur l'écran de l'imprimante, retirer la feuille en tirant dans le sens du papier, refermer.
Si le message persiste après deux tentatives, ouvrir un ticket matériel en précisant le numéro d'inventaire collé sur l'imprimante.
